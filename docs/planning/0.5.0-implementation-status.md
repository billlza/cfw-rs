### Direction confirmed on 2026-10-05

The older full-host roadmap and the component-focused correction were recorded
below as an unresolved conflict. The user settled it on 2026-10-05: Liquid Glass
is to strengthen the existing interface while inheriting its layout and style,
and the interface is not to be rebuilt from nothing. A full SwiftUI host is
therefore not a 0.5.0 goal. Roadmap targets that presume such a host, including
the memory and launch figures, have not been restated and need a decision.

Also decided that day: 0.4.0 is not published from frozen 40073. It first gains
an in-app installation so that 0.4.0 clients can install 0.5.0 themselves; that
needs a new 0.4.0 build with its release evidence run again. 0.3.5 clients cannot
authenticate later archives and still install from the disk image.
