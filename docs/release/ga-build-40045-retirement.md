`retired_product_change_after_install_before_ga_runtime_acceptance`. The user

## Product-change successor

Build 40046 is the single active successor, and 40045 is its observed installed
predecessor. Normal mode requests must use the existing native coordinator and
report actual ownership, permission, credential and unfinished-transaction
errors. Optional legacy maintenance retains explicit destructive confirmation
and recovery; the successor must not manufacture a cleared marker or bypass
an unfinished cutover journal.

The successor requires its own source, hosted CI, frozen application, signing,
notarization, source/legal closure, package sets, guarded 40045-to-40046 install,
ordinary GA runtime acceptance and publication verification. Ordinary runtime
acceptance uses normal mode controls without legacy preparation or confirmation.
Existing release-tooling fixes and the ordinary-GA versus assurance boundary
carry forward.

`target/candidates/0.4.0/ga/40045`, signed application, prepackage seal, receipts,
installed journals and backups must not be rebuilt, re-signed, overwritten or
relabelled as 40046 evidence. Earlier predecessor definitions and retirement
documents retain their original historical meaning; the allocation ledger
